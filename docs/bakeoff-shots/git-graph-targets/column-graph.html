Target visual · code-built · reviewed

One column per worktree

MAIN is the left spine. Each open worktree owns a vertical column. A/B tests get a thin sub-column beside their parent only, run down, then either merge back into that worktree column or go gray and die. No crossing the whole board.

Rules 1. MAIN = one continuous vertical column 2. Each WORKTREE = its own vertical column (many open OK) 3. A/B = sub-column under that worktree only 4. Winner: vertical run → rejoin parent worktree (MERGE) 5. Loser: vertical run → gray DEAD stub (no merge) 6. Lines never spaghetti across unrelated worktrees
